# Security

## Reporting Security Issues

Please report security concerns through GitHub Issues or repository discussions. Do not include API keys, cookies, private notes, or other secrets in public reports.

## Supported Versions

The currently supported release is `v1.0.0`.

## Security Boundaries

Notes are saved locally by default.

AI, search, and Luogu features may access external services when the user enables and uses them.

Users should configure API keys and cookies carefully, and should avoid sharing logs or screenshots that contain keys, cookies, private notes, or other sensitive data.
