# OI Notebook v0.1 同学试用说明

这是一份早期预览版，不是正式发布版。它主要用于让同学先体验本地记笔记、本地博客预览和 AI 辅助整理这几条核心流程，可能还有粗糙界面、打包兼容性和边界情况问题。

## 安装建议

优先发送 NSIS 安装包：

```text
oi-notebook_0.1.0_x64-setup.exe
```

也有 MSI 包可选：

```text
oi-notebook_0.1.0_x64_en-US.msi
```

Windows 可能提示“未知发布者”或类似安全提醒，这是因为当前还没有代码签名。确认来源是 Hardy 发出的安装包后再继续安装。

## 本地数据目录

第一次启动会在 Windows 用户目录下创建本地数据：

```text
%APPDATA%\io.github.hardyz0517.oi-notebook
```

其中：

- `notes/` 存放 Markdown 笔记和图片资源。
- `.oinb/` 存放 AI 配置、Prompt 模板和本地缓存。

这些数据默认留在本机，不代表已经云同步。

## 建议试用流程

1. 新建一篇 Markdown 笔记，写几行标题、列表、代码或普通文字，然后保存。
2. 关闭并重新打开应用，确认刚才的笔记还在。
3. 点击“打开博客”，访问本地博客首页。
4. 在博客首页找到刚才的笔记，并进入单篇详情页查看 Markdown 渲染。
5. 在笔记中插入或粘贴一张小图片，保存后到博客详情页确认图片能显示。
6. 打开“AI 设置”，填入自己的 OpenAI-compatible API 配置。
7. 在有 API 配置后，试用 AI 元数据补全或全文润色；未配置 API 时不应影响普通记笔记和博客预览。

## 已知限制

- Git 自动 commit / push 暂不建议同学使用。
- GitHub Pages 发布暂时只适合 Hardy 自己仓库。
- 洛谷同步暂不建议同学试。
- 本地博客是 production preview，不完全等同 Astro 开发博客。
- KaTeX、Shiki、表格、TOC 等 production blog 高级渲染可能还不完整。
- 如果本机端口 `4321` 被占用，博客可能打不开。
- 如果 `Ctrl+Alt+Space` 被占用，全局速记可能不可用。
- 这是早期预览版，不承诺自动同步、云同步或正式发布质量。
