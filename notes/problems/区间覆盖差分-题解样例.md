## 题意简述

给定长度为 $n$ 的序列，初始每个位置都是 $0$。现在有 $m$ 次操作，每次给一个区间 $[l, r]$ 加一。

最后需要回答：

- 每个位置被覆盖了多少次；
- 或者有多少个位置被覆盖至少一次；
- 或者最大覆盖次数是多少。

## 暴力做法

对每个区间直接枚举：

```cpp
for (int i = l; i <= r; i++) {
    a[i]++;
}
```

如果 $n, m$ 都是 $10^5$，最坏复杂度是 $O(nm)$，肯定会超时。

## 差分思想

如果我们想让 $[l, r]$ 全部加一，不一定要真的修改每个点。

只需要记录：

```cpp
diff[l] += 1;
diff[r + 1] -= 1;
```

最后从左到右做前缀和：

```cpp
a[i] = a[i - 1] + diff[i];
```

这样每次操作只改两个位置，总复杂度变成：

$$
O(n + m)
$$

## 为什么这样是对的

`diff[l] += 1` 表示从位置 `l` 开始，覆盖次数增加一。

`diff[r + 1] -= 1` 表示从位置 `r + 1` 开始，刚才那次覆盖结束。

所以在前缀和过程中，区间内部都会带着这次加一，离开区间后又抵消掉。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 200000 + 5;
int diff[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    while (m--) {
        int l, r;
        cin >> l >> r;
        diff[l]++;
        diff[r + 1]--;
    }

    int cur = 0;
    int covered = 0;
    int mx = 0;

    for (int i = 1; i <= n; i++) {
        cur += diff[i];

        if (cur > 0) covered++;
        mx = max(mx, cur);

        cout << cur << " \n"[i == n];
    }

    cerr << "covered = " << covered << '\n';
    cerr << "max cover = " << mx << '\n';

    return 0;
}
```

## 边界问题

### 1. 数组要开到 `n + 2`

因为会访问 `diff[r + 1]`。如果 `r = n`，就会访问 `diff[n + 1]`。

### 2. 下标从 1 开始还是 0 开始

如果题目区间是 1-indexed，最好代码也保持 1-indexed，减少心智负担。

如果使用 0-indexed，区间 `[l, r]` 的结束位置仍然是 `r + 1`，但循环范围要重新检查。

### 3. 覆盖和赋值不是一回事

差分适合处理“区间加法”。如果题目是“区间赋值为某个数”，就不能直接用普通差分解决，需要线段树、扫描线或离线技巧。

## 变形

- 二维差分：矩形区域加法；
- 树上差分：路径加法统计；
- 前缀差分结合二分答案；
- 差分 + 贪心，用来判断最少操作次数。

## 一句话总结

> 差分的本质是：不记录每个点发生了什么，而是只记录变化从哪里开始、在哪里结束。
