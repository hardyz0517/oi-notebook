#题解格式化强测试

##题意

给定n个点,m条边的有向图.每条边有权值w,要求从1号点到n号点的最短路.

如果不存在路径,输出-1.

数据范围满足 $1<=n<=10^5$,$1<=m<=2*10^5$,$0<=w<=10^9$,所以答案可能超过int范围,需要使用long long.

题目链接:[洛谷P0000,URL不要动](https://www.luogu.com.cn/problem/P0000?name=a.b&list=1,2,3)

图片链接:![测试图片,URL不要动](https://example.com/a,b.c.png)

##思路

这题可以使用Dijkstra算法.

我们设 $dis_i$ 表示从1号点到i号点的最短距离.初始化 $dis_1=0$,其它点 $dis_i=inf$.

每次从优先队列里取出当前距离最小的点u,枚举它的出边 $u->v$.如果 $dis_u+w<dis_v$,就更新 $dis_v=dis_u+w$.

因为所有边权满足 $w>=0$,所以当一个点第一次被弹出时,它的最短路已经确定.

这里要注意几个公式格式:

当 $a<=b$ 时,应该写成LaTeX的不大于符号.

当 $x>=y$ 时,应该写成LaTeX的不小于符号.

当 $a!=b$ 时,应该写成LaTeX的不等于符号.

当 $f_i->f_{i+1}$ 时,应该写成LaTeX箭头.

当 $g_i<-g_{i-1}$ 时,也应该写成LaTeX箭头.

当 $1...n$ 时,省略号应该规范化.

当 $inf$ 表示无穷大时,可以考虑转换成LaTeX.

当 $sum_{i=1}^n a_i$ 表示求和时,可以考虑转换成LaTeX.

但是普通文字里的 a->b 只是代码或者指针写法,不应该被强行改成LaTeX.

同理,普通文字里的 cnt<=n 如果不是公式,也不应该被转成LaTeX.

##代码块保护测试

下面代码块内部必须完全保持,不能改代码里的空格,不能把 `a<=b` 转成 `\le`,不能把 `i->next` 转成LaTeX.

```C++ showLineNumbers
#include <bits/stdc++.h>
using namespace std;

const int N=100005;
const long long INF=4e18;

struct Edge{
    int to,w;
};

int n,m;
vector<Edge> g[N];
long long dis[N];

int main(){
    cin>>n>>m;
    for(int i=1;i<=m;i++){
        int u,v,w;
        cin>>u>>v>>w;
        g[u].push_back({v,w});
    }

    priority_queue<pair<long long,int>,vector<pair<long long,int>>,greater<pair<long long,int>>> q;
    for(int i=1;i<=n;i++) dis[i]=INF;
    dis[1]=0;
    q.push({0,1});

    while(!q.empty()){
        auto [d,u]=q.top();
        q.pop();

        for(auto e:g[u]){
            int v=e.to,w=e.w;
            if(dis[u]+w<=dis[v]){
                dis[v]=dis[u]+w;
                q.push({dis[v],v});
            }
        }
    }

    if(dis[n]>=INF/2) cout<<-1<<"\n";
    else cout<<dis[n]<<"\n";
}
```

##正确性证明

由于边权满足 $w>=0$,所以每次堆顶的点u一定是当前未确定点中dis最小的点.

假设存在一条更短路径到u,那么这条路径上一定存在某个还没确定的点x.由于边权非负,所以 $dis_x<=dis_u$,这与u是堆顶最小点矛盾.

因此,每个点第一次被弹出时,最短路已经确定.

最终,如果 $dis_n<inf$,那么 $dis_n$ 就是答案.否则无解.

##复杂度

每条边最多松弛一次,每次操作优先队列复杂度为 $O(logm)$.

所以总复杂度是 $O((n+m)logm)$,空间复杂度是 $O(n+m)$.

##总结

这个测试主要看格式化工具是否只修改格式,不改变意思.

它应该处理中文英文数字空格,中文标点,公式符号,公式周围空格,标题空行,代码块前后空行,代码块语言名.

它不应该改代码块内部,不应该改inline code内部,不应该破坏链接URL,不应该破坏图片URL,不应该破坏表格,也不应该把普通文本里的a->b乱改成LaTeX.
