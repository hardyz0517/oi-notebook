# 漏洞百出的题解测试

## 题意

给定 $n$ 个点，$m$ 条边的有向图。每条边有一个权值 $w$，要求从 $1$ 号点到 $n$ 号点的最短路。

如果不存在路径，输出 $-1$。

数据范围满足 $1 \le n \le 10^5$，$1 \le m \le 2 \times 10^5$，$0 \le w \le 10^9$。所以答案可能超过 int 范围，需要开 long long。

题目链接：[洛谷 P0000，这个 URL 不要被破坏](https://www.luogu.com.cn/problem/P0000?name=a.b&list=1,2,3)

图片链接：![测试图片，这个 URL 也不要被破坏](https://example.com/a,b.c.png)

## 思路

这是一道 Dijkstra 模板题，但是很多人会写错。

我们设 $dis_i$ 表示从 $1$ 号点到 $i$ 号点的最短距离。初始化时 $dis_1 = 0$，其它点 $dis_i = \infty$。

每次从 priority_queue 里面取出当前 dis 最小的点 $u$，然后枚举它的所有出边 $u \to v$。如果 $dis_u + w < dis_v$，那么就更新 $dis_v = dis_u + w$。

因为所有边权满足 $w \ge 0$，所以每个点第一次被弹出时，它的最短路已经确定。

这里有很多公式应该被规范：

若 $a \le b$，则 $a$ 不大于 $b$。

若 $x \ge y$，则 $x$ 不小于 $y$。

若 $a \ne b$，则 $a$ 和 $b$ 不相等。

若 $f_i \to f_{i+1}$，应该是状态转移。

若 $g_i \leftarrow g_{i-1}$，也应该是箭头。

若 $1 \cdots n$，应该是省略号。

若 $\sum_{i=1}^n a_i$ 表示求和，应该考虑是否需要规范。

若 $\infty$ 表示无穷大，应该考虑是否转换。

但是普通文本里的 a->b 只是指针写法，不应该强行变成 LaTeX。

普通文本里的 cnt<=n 如果不是数学公式，也不应该被强行改成公式。

## 代码块语言名测试

下面这个代码块的语言名应该从 C++ 规范成 cpp，但代码块内部必须完全不动。

```cpp showLineNumbers
#include <bits/stdc++.h>
using namespace std;

const int N=100005;
const long long INF=4e18;

struct Edge{
    int to,w;
};

int n,m;
vector<Edge> g[N];
long long dis[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin>>n>>m;
    for(int i=1;i<=m;i++){
        int u,v,w;
        cin>>u>>v>>w;
        g[u].push_back({v,w});
    }

    priority_queue<pair<long long,int>,vector<pair<long long,int>>,greater<pair<long long,int>>> q;
    for(int i=1;i<=n;i++) dis[i]=INF;
    dis[1]=0;
    q.push({0,1});

    while(!q.empty()){
        auto [d,u]=q.top();
        q.pop();

        for(auto e:g[u]){
            int v=e.to,w=e.w;
            if(dis[u]+w<=dis[v]){
                dis[v]=dis[u]+w;
                q.push({dis[v],v});
            }
        }
    }

    if(dis[n]>=INF/2) cout<<-1<<"\n";
    else cout<<dis[n]<<"\n";

    return 0;
}
```

## 正确性证明

首先，堆中每次弹出的点 $u$ 满足当前 $dis_u$ 最小。

假设存在一条更短路径到 $u$，那么这条路径上一定存在某个还没有确定的点 $x$。由于边权非负，所以 $dis_x \le dis_u$。这与 $u$ 是当前堆顶最小点矛盾。

因此，每个点第一次被弹出时，它的最短路已经确定。

最终，如果 $dis_n < \infty$，那么 $dis_n$ 就是答案。否则无解。

## 复杂度分析

每条边最多被松弛一次，每次堆操作复杂度为 $O(\log m)$。

所以总复杂度是 $O((n + m)\log m)$，空间复杂度是 $O(n + m)$。
