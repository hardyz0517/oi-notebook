#漏洞百出的题解测试

##题意

给定n个点,m条边的有向图.每条边有一个权值w,要求从1号点到n号点的最短路.

如果不存在路径,输出-1.

数据范围满足1<=n<=10^5,1<=m<=2*10^5,0<=w<=10^9.所以答案可能超过int范围,需要开long long.

题目链接:[洛谷P0000,这个URL不要被破坏](https://www.luogu.com.cn/problem/P0000?name=a.b&list=1,2,3)

图片链接:![测试图片,这个URL也不要被破坏](https://example.com/a,b.c.png)

##思路

这是一道Dijkstra模板题,但是很多人会写错.

我们设dis_i表示从1号点到i号点的最短距离.初始化时dis_1=0,其它点dis_i=inf.

每次从priority_queue里面取出当前dis最小的点u,然后枚举它的所有出边u->v.如果dis_u+w<dis_v,那么就更新dis_v=dis_u+w.

因为所有边权满足w>=0,所以每个点第一次被弹出时,它的最短路已经确定.

这里有很多公式应该被规范:

若$a<=b$,则a不大于b.

若$x>=y$,则x不小于y.

若$a!=b$,则a和b不相等.

若$f_i->f_{i+1}$,应该是状态转移.

若$g_i<-g_{i-1}$,也应该是箭头.

若$1...n$,应该是省略号.

若$sum_{i=1}^n a_i$表示求和,应该考虑是否需要规范.

若$inf$表示无穷大,应该考虑是否转换.

但是普通文本里的a->b只是指针写法,不应该强行变成LaTeX.

普通文本里的cnt<=n如果不是数学公式,也不应该被强行改成公式.

##代码块语言名测试

下面这个代码块的语言名应该从C++规范成cpp,但代码块内部必须完全不动.

```C++ showLineNumbers
#include <bits/stdc++.h>
using namespace std;

const int N=100005;
const long long INF=4e18;

struct Edge{
    int to,w;
};

int n,m;
vector<Edge> g[N];
long long dis[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin>>n>>m;
    for(int i=1;i<=m;i++){
        int u,v,w;
        cin>>u>>v>>w;
        g[u].push_back({v,w});
    }

    priority_queue<pair<long long,int>,vector<pair<long long,int>>,greater<pair<long long,int>>> q;
    for(int i=1;i<=n;i++) dis[i]=INF;
    dis[1]=0;
    q.push({0,1});

    while(!q.empty()){
        auto [d,u]=q.top();
        q.pop();

        for(auto e:g[u]){
            int v=e.to,w=e.w;
            if(dis[u]+w<=dis[v]){
                dis[v]=dis[u]+w;
                q.push({dis[v],v});
            }
        }
    }

    if(dis[n]>=INF/2) cout<<-1<<"\n";
    else cout<<dis[n]<<"\n";

    return 0;
}
```

##数学公式密集测试

这里有$a<=b$,$b>=c$,$a!=c$,$f_i->f_{i+1}$,$g_i<-g_{i-1}$,$1...n$,$sum_{i=1}^n a_i$,$inf$.

还有行内公式没有空格:如果$a_i<=a_{i+1}$那么答案不变.

还有块级公式:

$$
f_i=min(f_i,f_j+w)
$$

$$
1<=i<=n
$$

##正确性证明

首先,堆中每次弹出的点u满足当前dis_u最小.

假设存在一条更短路径到u,那么这条路径上一定存在某个还没有确定的点x.由于边权非负,所以dis_x<=dis_u.这与u是当前堆顶最小点矛盾.

因此,每个点第一次被弹出时,它的最短路已经确定.

最终,如果dis_n<inf,那么dis_n就是答案.否则无解.

##复杂度分析

每条边最多被松弛一次,每次堆操作复杂度为O(logm).

所以总复杂度是O((n+m)logm),空间复杂度是O(n+m).

它应该处理中文英文数字空格,中文标点,公式符号,公式周围空格,标题空行,标题#后的空格,代码块前后空行,代码块语言名.
