## 题目要点

给一棵有根树，多次询问两个节点 $u, v$ 的最近公共祖先。

暴力往上跳会退化成 $O(n)$，如果询问很多次就不够快。倍增做法可以做到：

- 预处理：$O(n \log n)$
- 单次查询：$O(\log n)$

## 核心定义

令：

$$
fa[u][k]
$$

表示节点 $u$ 向上跳 $2^k$ 步后到达的祖先。

那么有递推：

$$
fa[u][k] = fa[fa[u][k - 1]][k - 1]
$$

也就是先跳 $2^{k-1}$ 步，再从那个祖先继续跳 $2^{k-1}$ 步。

## 查询流程

查询 `lca(u, v)` 时分三步：

1. 如果两个点深度不同，先让更深的点往上跳；
2. 如果跳完后两个点相同，说明其中一个就是 LCA；
3. 否则从大到小枚举 `k`，只要 `fa[u][k] != fa[v][k]`，就一起往上跳；
4. 最后它们的父亲就是 LCA。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
const int LOG = 20;

int n, m, s;
int dep[N], fa[N][LOG + 1];
vector<int> g[N];

void dfs(int u, int p) {
    fa[u][0] = p;
    dep[u] = dep[p] + 1;

    for (int k = 1; k <= LOG; k++) {
        fa[u][k] = fa[fa[u][k - 1]][k - 1];
    }

    for (int v : g[u]) {
        if (v == p) continue;
        dfs(v, u);
    }
}

int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);

    int diff = dep[u] - dep[v];
    for (int k = LOG; k >= 0; k--) {
        if (diff & (1 << k)) {
            u = fa[u][k];
        }
    }

    if (u == v) return u;

    for (int k = LOG; k >= 0; k--) {
        if (fa[u][k] != fa[v][k]) {
            u = fa[u][k];
            v = fa[v][k];
        }
    }

    return fa[u][0];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m >> s;

    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    dfs(s, 0);

    while (m--) {
        int u, v;
        cin >> u >> v;
        cout << lca(u, v) << '\n';
    }

    return 0;
}
```

## 调试时发现的问题

### 1. `LOG` 要够大

如果 $n \le 5 \times 10^5$，那么 $2^{19} = 524288$，所以 `LOG = 20` 比较稳。

### 2. 根节点的父亲可以设为 0

这样 `fa[0][k] = 0`，递推不会炸。

### 3. DFS 可能爆栈

如果树退化成链，递归 DFS 可能栈溢出。正式写法可以考虑改成 BFS 或手动栈。

## 复习提示

LCA 倍增不仅能求最近公共祖先，还经常和这些东西组合：

- 树上距离；
- 路径最大值 / 最小值；
- 虚树；
- 树上差分；
- 在线倍增跳祖先。

树上距离公式：

$$
dist(u, v) = dep[u] + dep[v] - 2 \cdot dep[lca(u, v)]
$$

## 一句话总结

> 倍增 LCA 的关键不是“跳得快”，而是先把“向上跳 2 的幂次步”这个动作预处理成表。
