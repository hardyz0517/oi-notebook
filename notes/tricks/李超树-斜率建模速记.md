## 适用场景

有些 DP 转移看起来很复杂：

$$
f_i = \min_{j < i} (f_j + A_j \cdot B_i + C_i)
$$

把和 $j$ 有关、和 $i$ 有关的部分拆开：

- 对每个历史状态 $j$，它贡献一条直线；
- 当前状态 $i$，相当于拿一个 $x = B_i$ 去查询最小值；
- $C_i$ 是只和当前点有关的常数，最后加上即可。

于是每个 $j$ 对应：

$$
y = A_j x + f_j
$$

查询：

$$
f_i = \min_j y_j(B_i) + C_i
$$

## 为什么不是普通凸包

普通斜率优化通常要求：

- 插入直线斜率单调；
- 查询点 $x$ 单调；
- 或者能离线排序。

但李超树不太要求这些。它适合处理：

- 插入顺序乱；
- 查询点乱；
- 斜率不单调；
- 只需要在一个固定值域内查询最优直线。

代价是复杂度多一个 $\log V$，其中 $V$ 是横坐标值域大小。

## 李超树维护的东西

每个线段树节点负责一个区间 $[l, r]$。

节点上保存一条“当前在这个区间中部比较优秀”的直线。插入新直线时，在左端点、中点、右端点比较两条线谁更优，然后把较差的一条递归下放到可能反超的半边。

## 最小值版本核心代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long INF = (1LL << 62);

struct Line {
    long long k, b;

    long long get(long long x) const {
        return k * x + b;
    }
};

struct LiChao {
    struct Node {
        Line line;
        bool has = false;
    };

    vector<Node> tr;
    long long L, R;

    LiChao(long long l, long long r) : L(l), R(r) {
        tr.resize((R - L + 5) * 4);
    }

    void add_line(Line nw) {
        add_line(1, L, R, nw);
    }

    long long query(long long x) {
        return query(1, L, R, x);
    }

    void add_line(int p, long long l, long long r, Line nw) {
        if (!tr[p].has) {
            tr[p].line = nw;
            tr[p].has = true;
            return;
        }

        long long mid = (l + r) >> 1;
        Line cur = tr[p].line;

        if (nw.get(mid) < cur.get(mid)) {
            swap(nw, tr[p].line);
            cur = tr[p].line;
        }

        if (l == r) return;

        if (nw.get(l) < cur.get(l)) {
            add_line(p << 1, l, mid, nw);
        } else if (nw.get(r) < cur.get(r)) {
            add_line(p << 1 | 1, mid + 1, r, nw);
        }
    }

    long long query(int p, long long l, long long r, long long x) {
        long long ans = tr[p].has ? tr[p].line.get(x) : INF;
        if (l == r) return ans;

        long long mid = (l + r) >> 1;
        if (x <= mid) return min(ans, query(p << 1, l, mid, x));
        return min(ans, query(p << 1 | 1, mid + 1, r, x));
    }
};
```

## 常见坑点

- 值域要提前确定，不能随便写死成 `1e9` 然后数组开炸。
- `k * x + b` 可能爆 `int`，一般用 `long long`。
- 如果是最大值，把比较方向反过来即可。
- 如果 $x$ 需要离散化，注意李超树比较的是实际横坐标，不是离散后的下标。
- 有些题需要动态开点李超树，而不是固定数组。

## 建模检查表

看到一个转移时，可以问自己：

1. 能否写成 `历史状态贡献一条函数`？
2. 当前状态是否只是查询某个 `x`？
3. 历史函数是不是一次函数？
4. 查询的是最大值还是最小值？
5. 横坐标范围是否能确定？

如果这五个问题都能回答，李超树就值得尝试。
