## 今天遇到的坑

### 1. `long long` 没开

有个式子看起来每一项都不大，但乘起来就超过 `int` 了：

```cpp
ans += 1LL * a[i] * b[i];
```

以后看到乘法求和，先条件反射加 `1LL`。

### 2. 排序后忘记维护原编号

有一道题排序后还要输出原来的点编号，我直接把结构体排序了，但是没保存 `id`。

正确写法：

```cpp
struct Node {
    int x, y, id;
};
```

### 3. 二分边界写反

本来要找最小可行值，结果更新写成了：

```cpp
if (check(mid)) l = mid + 1;
else r = mid - 1;
```

应该是：

```cpp
if (check(mid)) r = mid;
else l = mid + 1;
```

## 以后训练时的 checklist

- 先估算数据范围，判断 `int` 还是 `long long`；
- 排序前想清楚是否需要原编号；
- 二分前写一句话：我要找“最大可行”还是“最小可行”；
- 写完样例后，自己造一个极端数据；
- 如果 WA，不要盲改，先定位是哪一段逻辑不满足不变量。

## 今日总结

今天真正的问题不是不会算法，而是实现时太急。

下次写题时可以慢一点，尤其是这些模板化但容易错的地方。
